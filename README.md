Studying - Backend

This project is the result of my Final Course Project, which I completed to graduate from Estácio de Sá University as one of the top students with the highest grades. It was an important milestone in my learning process and the starting point of my journey as a backend developer.

The project idea was to create a material aggregator where a student could find videos, documents, and summaries, and would have options for flashcards and favoriting items.

The backend for the Studying system was built with ASP.NET 5, using the CQRS pattern and libraries such as FluentValidation, MediatR, Entity Framework Core, SendGrid, Azure Blob, and more.
